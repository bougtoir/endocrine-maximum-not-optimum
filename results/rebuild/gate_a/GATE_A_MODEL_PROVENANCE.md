## Upstream implementation caveat

The upstream pure-MATLAB AutoTester clamps every variable to `VARMAX(v+1)` after each step (`SorensenForceVars.m`). For the insulin-infusion variable this bound is 1000 pmol/min, so a direct upstream IVITT run delivers 3,100 instead of 19,443 pmol. Lifting this bound (`analysis/rebuild/octave/run_upstream.m ... nocap`) makes upstream and Python agree. The Python port therefore implements the protocol as specified; the bound is an artefact of the upstream test harness, not of the model.
